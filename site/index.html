Zest is a free cleaner and optimizer for Windows. It finds what is wasting space and slowing your PC down, shows you every item, and removes only what you approve.

One orange, eight segments

Everything a paid optimizer suite does, in one native program that costs nothing.

Clean
Temporary files, caches, logs, crash dumps, the Recycle Bin and browser data, across every Windows account if you want. Health check sums it up in one view.
Registry
Fifteen kinds of invalid entries. Each fix is saved to a standard .reg file first and can be put back with one click.
Privacy
Switches for what Windows collects and advertises, a cookie keep list so you stay signed in where you choose, and secure deletion in 1, 3, 7 or 35 passes.
Speed
Start-up apps, scheduled tasks, services and context menus with reversible switches. Put heavy background apps to sleep until you use them.
Software
Uninstall programs and sweep up what they leave behind. Update apps through Windows Package Manager and drivers through Windows Update.
Storage
See what fills a drive, find duplicate files and empty folders, wipe free space or erase a whole drive.
Backup
Versioned, deduplicated backups of your folders that you can browse and restore file by file, plus full system images made with Windows' own imaging engine.
System
Hardware inventory with drive and battery health, Windows' repair tools one click away, and restore points before big changes.

How a clean goes

A cleaner deletes things for a living, so nothing here happens behind your back.

  1. Analyze

    Zest reads, counts and measures. Nothing changes on your PC during this step, however often you run it.

  2. Review

    Every file and registry entry is listed with its size and location. Untick a rule, a folder or a single item, or exclude it for good.

  3. Guard

    Windows folders, your documents and anything behind a link or junction are refused outright. Registry changes are exported to a .reg backup before they are made.

  4. Clean

    Only what you approved is removed. The run is written to a history you can read later, and a registry clean can be reversed from its backup.

Why trust a cleaner?

Because you can check this one.

  • All of the code is public. Apache 2.0, written in Rust, on GitHub.
  • It keeps to itself. No telemetry, no ads, no account. Zest goes online for two things: its own update check, and the software catalog when you ask for updates. Both can be switched off.
  • Downloads are built in the open. Every release is compiled by GitHub Actions from the tagged source, with SHA-256 checksums and a build attestation you can verify.
  • It says what has been tested. The feature plan lists, feature by feature, how far each one has been verified.
  • It is one native program. No web view, no background service, no runtime to install. The same engine runs from the command line and on a schedule.

From source

With Rust 1.92 or later and the Visual Studio build tools:

git clone https://github.com/SkippyNet/zest
cd zest
cargo build --release

Windows SmartScreen may warn about a new download that is not code-signed yet. Choose More info, then Run anyway, or compare the file with SHA256SUMS.txt from the release first. All releases and checksums.
