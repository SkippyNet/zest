# Speed

## Startup

Everything that starts by itself, in four tabs: **startup apps** (registry Run keys and Startup
folders), **scheduled tasks**, **services** and **context menu** entries in Explorer.

- The switch turns an entry off without removing it, the same way Windows' own Task Manager does.
  Turn it back on at any time.
- The bin icon removes an entry. The program itself is not uninstalled, and a backup of the entry
  is saved first.
- **Missing** marks an entry whose program no longer exists. Those are safe to remove.
- Entries that apply to every user of the PC need administrator rights; Zest offers to restart
  itself as administrator.
- Microsoft's own entries are hidden unless you turn on *Options → General → Show Windows entries*.

A good rule: switch off, live with it for a few days, and only then remove.

## Performance

A live list of running apps with their processor and memory use, averaged over the last minute so
a brief spike does not mislead you.

- **Impact** rates each background app. A star marks a good candidate for sleeping: no window,
  and noticeable use of resources.
- The **Sleep** switch puts an app to sleep: Windows gives it the lowest priority and power
  (efficiency mode), or pauses it completely, depending on the app. Using the app wakes it.
- Apps that Windows itself depends on are marked **Protected** and cannot be put to sleep.
- **Free up memory** asks Windows to trim the memory of idle apps. The effect is real but
  temporary: apps take the memory back as they need it.
- Sleep rules apply while Zest or its background agent is running. Turn on
  *Options → Smart cleaning → Watch in the background* to keep them between sessions.

Power plans are on the same page: see which plan is active and switch between the ones your PC
offers.
